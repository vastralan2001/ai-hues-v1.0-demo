📖 使用指南

1. 下载预编译模型

$ bash models/download-ggml-model.sh base.en
# 可选: tiny, base, small, medium, large (越大越准越慢)

2. 编译项目

$ make
# 或 cmake: mkdir build && cd build && cmake .. && make -j

3. 转录音频

$ ./main -m models/ggml-base.en.bin -f samples/jfk.wav
# 输出文本到 stdout，支持 .wav, .mp3, .ogg 等

4. 实时流式识别（Mac）

$ ./stream -m models/ggml-base.en.bin --step 3000 --length 10000
# 从麦克风实时输入，3秒步进，10秒窗口

关键参数速查

-m 模型文件路径 必需
-f 输入音频文件 文件模式必需
-l 语言 (en, zh, ja...) 默认 auto-detect
-otxt/-osrt/-ovtt 输出格式 默认 stdout
-t N 使用 N 个线程 默认 4
-pp 输出概率分数 可选
-tp 输出时间戳 建议长音频开启
