# 想法结果页 — 原型规格（已确认）

**路由（建议）：** `GET /idea/result?q=...`（或 `POST` 后 `302` 到带 query 的 URL，避免刷新丢 body；原型可任选其一）  
**来源：** 首页主 CTA 提交想法后 **跳转至本独立页**（不与首页同页展示结果）。

---

## 页面目的

- 展示与当前想法 **匹配的开源仓库列表**。  
- 每条足够信息支撑用户 **点进详情** 或 **外链到 GitHub**。  
- 每条露出 **该仓库已有 Showcase（过往案例）** 与 **评论入口**。

---

## 结果列表 — 每条卡片 P0 字段（已全部要求）

| 字段 | 说明 |
|------|------|
| **仓库名** | 显示名 + 可选 `owner/repo` |
| **为何匹配** | 1～3 句可解释文案（原型占位即可） |
| **Hue 标签** | 与色环/领域一致的可视标签 |
| **外链** | 主链至 GitHub（或上游托管）仓库根或 README |
| **Showcase（仓库维度）** | **该开源项目此前已被记录的案例**（非首页那种「产品想法 A」）：如 2～3 条标题 + 「更多」进详情；无数据时显式「暂无收录案例」 |
| **评论** | **入口**至 **AI_Hues 站内社区评论区**（用户在我们网站留言的空间，非 GitHub Issues 替代）：见下节 |

---

## Showcase（仓库维度）与首页 Idea Showcase A 的区别

| 位置 | 类型 | 内容 |
|------|------|------|
| 首页 | **A · 产品想法案例** | 一句话 **idea**，偏灵感与选题 |
| 本结果页每条卡片 | **仓库历史案例** | 该 **repo 已被社区/编辑收录** 的落地或用法摘要 |

---

## 「评论」= 站内社区（已对齐产品语义）

- **定位：** AI_Hues 是 **社区型站点**；评论指 **登录用户（原型可占位）** 在 **我们站内** 就某个开源项目留下的讨论、踩坑、推荐组合等——**为社区用户留出表达空间**，与外链 GitHub 讨论区 **并存、不互相替代**。  
- **P0 呈现：** 每条结果卡片展示 **站内评论条数（或「参与讨论」）** → 跳转 **`/p/{slug}#comments`**，主讨论区做在 **项目详情页底部** 的 **Comments** 区块（同一套站内数据）。  
- **独立评论 URL（可选）：** 若运营需要强分享链接，可增加 **`/p/{slug}/comments`**，与详情页 **同数据源**；默认仍以 **`#comments`** 为 P0，避免双维护。

**MVP 实现提醒（非原型范围，仅备案）：** 登录、反垃圾、举报、审核队列；原型阶段可用静态示例 + 禁用发布框。
