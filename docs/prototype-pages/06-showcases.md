# 全局案例 `/showcases` · `/showcases/{id}` — 原型规格（**已确认**）

**定位：** 与 [`03-project-detail.md`](./03-project-detail.md) 中 **单项目 Showcase 区块** 配套：**跨仓库** 的 **精选落地案例索引**；与首页 **Idea Showcase A**（一句话产品想法）**命名相近但对象不同**——本页是 **「某开源栈被用在了什么场景」**。

### 分条确认记录（批量）

| 条 | 主题 | 结论 |
|---|------|------|
| 1 | 案例详情路由 | **D1**：**独立详情页** `/showcases/{id}`（故事 + 关联仓库列表，可分享）。 |
| 2 | 谁可贡献案例 | **C2**：**用户投稿 + 审核**（与 [`05-articles.md`](./05-articles.md) **E2** 同思路）；需 **状态**（待审 / 已发布 / 已拒）与审核占位。 |
| 3 | 列表筛选 P0 | **F3**：**按仓库 slug** 与 **按主题标签** 筛选 **均为 P0**（可并存于筛选条）。 |
| 4 | 首页露出 | **H1**：首页需 **「Featured showcases / 精选案例」** 区块 + 「查看全部」→ `/showcases`；已回写 [`01-home.md`](./01-home.md)。 |

---

## 与项目详情里 Showcase 的关系

| 位置 | 内容 |
|------|------|
| `/p/{slug}` | **该仓库** 被收录的案例 **子集视图**（过滤 `slug`） |
| `/showcases`、`/showcases/{id}` | **全站** 案例库；一条 Case **可挂 1…n 个** `slug` |

**数据关系：** Case 实体独立存储；详情页按 `slug` 过滤关联 Case。

---

## P0 模块

### 列表 `/showcases`

- **案例卡片**：标题（场景）、**关联开源项目**（链 `/p/{slug}`）、可选封面占位、→ `/showcases/{id}`  
- **筛选**：**仓库** + **主题标签**（F3）  
- **投稿入口**（C2）：链到表单或 `/showcases/submit` 占位  
- **空状态**

### 详情 `/showcases/{id}`

- 叙事正文（Markdown 静态可）  
- **关联仓库** 列表 + Hue 标签  
- **外链**（若案例有公开站点）可选  
- **评论区**（可选 P1；若与文章/项目评论三套，需单独评估——**当前未强制 P0**，与产品再开议题时可加）
