# 文章 `/articles` · `/articles/{slug}` — 原型规格（**已确认**）

**定位：** 站内 **原创 / 转载经授权** 的长文，帮助「非资深开发者」理解技术选型；与 **GitHub README / Blog 外链** 互补（外链作「来源」或延伸阅读，不替代正文价值）。  
**Hues 呈现：** 每篇 **Hues 特写** 须含 **六维快照表**（与 [`../HUES-scoring-dimensions.md`](../HUES-scoring-dimensions.md) 一致）+ **Hue · 领域** 分类条 + 免责声明（演示分 / 真管线）。

### 分条确认记录（批量）

| 条 | 主题 | 结论 |
|---|------|------|
| 1 | 文章站内评论 | **A2**：**正文页 P0 含评论区**（与 **项目页 `/p/{slug}#comments`** 分库、分 UI 语境；需登录、反垃圾、举报，与 PRD 合规一致）。 |
| 2 | 正文语言 | **L1**：**中英文章均存在**；列表支持 **按语言筛选** 或每条标注 **`EN` / `ZH`**（与全站语言策略一致）。 |
| 3 | 发稿主体 | **E2**（**用户澄清**：此前所写「E3」即 **E2**）：**开放投稿 + 审核** 后上架；需 **投稿入口、审核队列、状态**（草稿 / 待审 / 已拒 / 已发布）占位，与运营流程对齐。 |
| 4 | 首页露出 | **H1**：首页需 **「最新文章」** 区块（或等价模块），链至 `/articles`；已回写 [`01-home.md`](./01-home.md)。 |
| 5 | 转载 | **R1**：**允许转载**，须 **显著署名 + 原文链接**；正文或元信息区固定展示。 |

## 路由

- `/articles` — 列表（含语言筛选 / 标签占位）  
- `/articles/{slug}` — 正文 + **参考链接** + **关联项目** + **评论区**

---

## P0 模块

### 列表页

- 标题、摘要、发布日期、**语言**（`EN`/`ZH` 或 filter）、**关联项目**（0～n → `/p/{slug}`）、阅读时长占位。

### 正文页

- 标题、作者、日期、Markdown 正文  
- **关联项目**（侧栏或文内）  
- **参考链接**（经审核的 `github.com` / `github.blog` 等）  
- **评论区**（A2）：列表 + 排序（最新优先）；发帖需登录（原型可禁用发布器）  
- **转载声明**（R1）：若 `is_reprint`，展示原文链接与署名模板
