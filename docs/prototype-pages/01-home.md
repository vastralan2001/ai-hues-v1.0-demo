# 首页 `/` — 原型规格（已确认）

**状态：** 已与产品方对齐（Showcase **A**；关键词 **①**）  
**语言：** 原型阶段可中英切换，文案另表。

---

## 信息顺序（自上而下）

1. 价值主张 + Slogan（一行或极短块）  
2. **主 CTA：首屏直接输入想法**（大输入区；提交后 **跳转至独立结果页**，见 [`02-idea-result.md`](./02-idea-result.md)）  
3. **关键词**：可点标签；**点击后填入上方想法输入框**（**①**），用户可编辑后再发起搜索  
4. **Idea Showcase**：主 CTA 下方；内容为 **A — 产品想法案例**（一句话 idea + 可选关联开源/标签；点击可进入详情或故事占位）  
5. **Featured showcases（精选落地案例）**：与 [`06-showcases.md`](./06-showcases.md) **H1** 一致；**仓库维度**案例卡片（≠ 第 4 条 Idea Showcase）；「查看全部」→ `/showcases`  
6. **Latest articles（最新文章）**：与 [`05-articles.md`](./05-articles.md) **H1** 一致；若干条卡片 + 「查看全部」→ `/articles`  
7. 页脚（PRD / 合规入口等）

---

## Showcase 类型 A（定义）

- 强调 **「想法」本身** 写得清楚、有吸引力。  
- 每条卡片可带：标题（idea 一句话）、可选标签、可选「推荐用到的 OSS」占位。  
- **不是**以「已上线产品截图」为主视觉的 B 类落地案例集（若后续要加 B，另开区块或 Phase 2）。

---

## 关键词交互 **①**（定义）

- 点击关键词 → **把该词写入想法输入框**（可拼接规则：替换 / 追加逗号，MVP 建议 **追加到末尾并加空格**，具体实现待技术稿）。  
- 不自动提交搜索，除非用户再点「搜索 / 找仓库」类按钮（避免误触）。  
- **不** 因点击关键词而跳转 `/explore`（**K1**，与 [`04-explore.md`](./04-explore.md) 第 6 条一致）；逛索引走顶栏或首页次要链接。
